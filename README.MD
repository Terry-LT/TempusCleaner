# Clean Temp
I created this script to clean up the temp folders on my pc.
I could use python but I realized to use C++ because it is fun :)
# Set up
## How to Run

### Option 1 — Visual Studio (recommended)

1. Open Visual Studio  
2. Click **File → Open → Folder**  
3. Select this project folder  
4. Press **Ctrl + F5**  


### Option 2 — Using CMake

```
mkdir build
cd build
cmake ..
cmake --build .
```
